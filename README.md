  <strong>VUPTH</strong> é uma plataforma de gerenciamento de filas e atendimentos
  desenvolvida para estabelecimentos de serviços.
</p><p>
  Este é meu primeiro <strong>MVP (Minimum Viable Product)</strong>, desenvolvido
  durante minha transição para a área de software com o objetivo de transformar
  estudo em experiência prática de desenvolvimento.
</p><p>
  O projeto foi desenvolvido de ponta a ponta, envolvendo definição de produto,
  regras de negócio, arquitetura, backend, banco de dados, segurança,
  comunicação em tempo real, testes, CI/CD e aplicações cliente.
